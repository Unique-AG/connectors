How to get an API token

  • In Backstop, open {{ profile_instructions }}. You can also click the person icon in the top right and choose Go to Profile.
  • In the API Security section, select Generate New Token.
  • Copy the token and paste it in the API token field above. Backstop uses the token in place of a password.
